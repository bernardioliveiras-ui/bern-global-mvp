# BERN NEXUS v0.5.6 — Clareza da proposta

Objetivo desta versão: uma pessoa que nunca ouviu falar do Bern Nexus deve entender o produto em poucos segundos.

## Mudanças

- “Missão” deixa de ser a palavra principal para o usuário.
- LP, trabalhador, contratante, Admin, Termos e Suporte passam a usar “tarefa”.
- Hero agora explica em linguagem direta:
  empresa publica → pessoa escolhe → faz → envia → recebe se aprovado.
- Nova seção “Entenda em 10 segundos” com os dois lados do marketplace.
- Exemplo concreto de tarefa paga de R$ 5.
- Fluxo separado para quem quer renda extra e para quem precisa de ajuda.
- Casos de uso concretos:
  landing page, criativo, pesquisa, experiência e opinião.
- Painel do trabalhador explica valor, prazo e instruções antes do aceite.
- Painel do contratante enfatiza pessoas reais e trabalhos recebidos.
- Botões “Fazer missão” passam para “Aceitar tarefa”.
- “Publicar missão” passa para “Publicar tarefa”.
- “Minhas missões” passa para “Minhas tarefas”.
- Textos padrão antigos salvos pelo Admin são migrados somente quando ainda forem exatamente os defaults antigos; textos personalizados são preservados.
