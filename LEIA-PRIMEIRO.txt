BERN NEXUS v0.2.2 — PATCH D1

O seu Worker em produção mostra:
binding: DB
database: bern-global-db

Este patch passa a executar migrations por:
wrangler d1 migrations apply DB --remote

IMPORTANTE:
1. NÃO substitua o seu wrangler.jsonc por um arquivo com placeholder.
2. No wrangler.jsonc existente, confirme que o bloco D1 tem:
   "binding": "DB"
   "database_name": "bern-global-db"
   "database_id": "<ID REAL DO bern-global-db>"
   "migrations_dir": "migrations"
3. Substitua no GitHub:
   - src.js
   - package.json
   - README.md
   - migrations/0001_initial.sql
4. Commit/push.
5. Depois do deploy, abra /api/health.

Não coloque o ID do Token de API no campo database_id.
O database_id é o UUID exibido na página do banco D1 bern-global-db.
